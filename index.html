Settings

"Keyframed" plays the effect's built-in animation (flash pulses, shake wiggle, zoom punch) at its normal preset length. "Constant" holds the effect at a static value with no animation and stretches the adjustment layer to match the full length of whatever clip is selected when you apply - useful for things like a color grade or steady shake that should run the whole clip instead of a short burst. Select a layer in the timeline before double-clicking to use Constant mode; with nothing selected it falls back to the rest of the comp.

Library

Rescan reloads data/effects-index.json without restarting AE. Generate previews requires the Phase 2 template project to be open - see tools/pending-presets/README.md. Import Preset copies a real, already-exported .ffx file straight into the library - it gets a placeholder thumbnail until you run it through the Preview Generator (or render one manually), but it's immediately searchable, categorized, and double-click-applicable via AE's native applyPreset().
